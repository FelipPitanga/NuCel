NUCEL — COMEÇAR AQUI
====================

FLUXO OFICIAL

GITHUB -> CLOUDFLARE WORKERS -> SUPABASE
                     |
                     -> NUCEL AGENT -> ADB -> CELULARES

1) SUPABASE
- O projeto NuCel já possui a estrutura de banco.
- No Cloudflare, cadastre:
  SUPABASE_URL
  SUPABASE_PUBLISHABLE_KEY
  SUPABASE_SECRET_KEY (como Secret)
  NUCEL_OWNER_EMAIL

2) GITHUB
- FelipPitanga/NuCel é a fonte oficial do código.
- Mantenha o repositório privado.
- A branch de produção é main.

3) CLOUDFLARE WORKERS
- Workers & Pages -> Create application -> Import a repository.
- Selecione FelipPitanga/NuCel.
- Production branch: main.
- Build command:
  npx opennextjs-cloudflare build
- Deploy command:
  npx opennextjs-cloudflare deploy
- Cadastre as quatro variáveis em Settings -> Variables & Secrets.
- Cada push na main gera novo deploy automaticamente.

4) PRIMEIRO ACESSO
- NUCEL_OWNER_EMAIL deve ser o e-mail do administrador principal.
- Crie a primeira conta usando exatamente esse e-mail.
- Depois cadastre colaboradores e escolha quais aparelhos cada um pode usar.

5) CONECTOR
- Os arquivos ficam em connector/.
- Configure config.json com a chave gerada pelo NuCel.
- allowed_origin deve ser exatamente a URL HTTPS final do Worker,
  sem barra no final.

Depois dessa configuração não é mais necessário baixar ZIP para atualizar o NuCel.
